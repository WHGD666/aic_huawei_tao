## 已修复的问题

| 环节 | 审核发现 | 修复 |
|---|---|---|
| 父代重建 | 工作目录位于仓库的 ignored 子目录时，`git apply` 可能返回 0 且报告 `Skipped patch`；旧实现还把 `--directory` 和工作目录重复叠加，错误会被复制父代工作目录掩盖 | 在独立工作目录应用补丁；跳过或失败即报错；仅 Git 不可用时使用父代工作副本 |
| 部分运行 | `--max-rounds` 提前结束后仍会进入 final 阶段，动用保留评估次数 | 主评估配额用完且轮数允许时才进入 final；final 同样受轮数限制 |
| 崩溃记录 | 准备工作目录或提出/检查候选时崩溃，候选状态可能留在 `proposed` | 记录 `error` 和失败原因；记录已发生的 LLM 费用；运行结束关闭日志文件 |
| 指标校验 | 官方 JSON 缺 WNS/TNS/溢出时可能被默认为 0；非有限值可能流入排序 | 缺失或无效的指标判为无效；基线要求完整的训练集和有效时序指标；日志目录同样拒绝非有限值 |
| 评估命令 | 命令退出非零但留下旧结果时，旧指标可能被判有效 | 命令非零时全部 run 标记无效 |
| 小预算 | 配置保留次数大于总预算时，单次试跑无法进入主循环；阶段缩放可能出现负次数 | 限制保留次数；阶段次数精确缩放，小预算从 probe 开始 |
| 门禁与去重 | 普通 `for ... in ...` 与工艺名同一行时被误判为分支；不同文件的相同改动被误判重复；按设计文件全集每轮递归扫描 | 缩窄条件正则；指纹保留文件路径；按 glob 枚举并缓存文件全集 |
| 产物与适配 | 删除最后一个候选目录后 ID 可能复用；种子写入参数文件后不恢复；任务一修复后指标别名错误；`--inplace` 可能污染原始源码 | 从血统事件恢复 ID；逐种子恢复原始参数字节；修正指标别名；限制 `--inplace` 为未编辑候选 |
| M2 日志 | `tee` 管道使脚本记录到日志命令的退出码 | 启用 `pipefail`，记录并返回真实流程退出码 |
| 测试入口 | 无 pytest 的后备运行器即使测试失败也返回成功；Windows 文本写入可能把补丁转成 CRLF | 失败时返回非零；补丁以 LF 写入 |
