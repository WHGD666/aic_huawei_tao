# 旋钮目录（Knob Catalog）—— 演化搜索的"假设菜单"

> 用途：harness 的 probe 阶段从这里挑"单旋钮"做敏感性探针；structural 阶段的提示词里引用机制编号。每条给出：改什么、预期对 WNS / TNS / 溢出 / 合法性风险 / runtime 的方向、跨算例泛化性、优先级。方向是先验判断，**以探针实测为准**，探针结果写回"实测"列。
>
> 优先级：A = 初赛任务一首选，B = 次选，C = 任务二 / 决赛再说。

## 探针阶段建议顺序（任务一，6 次）

1. L1 α=0.5（slack 网权重）— 最可能的大头
2. P2（关键网切割权重）
3. L3 / L2 密度 0.7→0.6（留缓冲空间）
4. P4 平衡容差放宽
5. L4 跨层网权重 ×2
6. P8 epochs ×2（看 GNN 是否欠训练）

每个探针只改一处、从基线出发，结果记回本表"实测"列；structural 阶段按实测排序组合。
