DOMAIN KNOWLEDGE (condensed; mechanisms, not recipes):
- Platform (Open3DBench NanGate45_3D): ONE design with 20 metal layers. metal1-10 = bottom die, hb_layer (cut) = hybrid bond, metal11-20 = upper die mirrored (upper cell pins sit on metal19). Every std cell exists as <cell>_bottom and <cell>_upper; tier assignment = choosing the master suffix. HBTs are 1um x 1um CORE macros HBT_BOTIN / HBT_TOPIN (pins metal10<->metal11, MUSTJOIN) inserted as virtual buffers on cross-tier nets. STA sees both tiers natively.
- Flow: partition (GNN tier assignment) -> bistratal analytical placement (DREAMPlace fork) -> merged DEF -> per-tier legalization (detailed_placement -max_displacement 300) -> PDN (fixed) -> HBT assignment -> timing repair (rsz: repair_design / repair_timing) -> [full_flow: CTS -> global routing] -> STA.
- Task partition_placement is scored right after ONE fixed timing-repair pass with placement-estimated parasitics and ideal clocks. You cannot change the repair; make its job easier: (a) critical paths short and same-tier or vertical, (b) room for buffers (density/padding), (c) avoid long cross-tier detours. Note: by default DONT_USE_CELLS forbids all *_upper BUF/CLKBUF, so rsz can only insert buffers on the bottom tier - critical logic placed on the upper tier is harder to repair.
- Task full_flow is scored after global routing with propagated clocks; the GRT congestion table's "Total" row (sum over all 20 layers) is the overflow; above 300 it is penalized without cap -> treat overflow <= 300 as a hard constraint.
- Levers that generalize: enable/tune DREAMPlace timing-driven net weighting (timing_opt_flag, net_weighting_scheme adam|lilith, max_net_weight, momentum_decay_factor); timing-criticality node features and critical-net edge weights in the GNN partition (baseline contrastive loss ignores edge weights); area-balance repair that flips low-degree / non-critical nodes instead of by embedding distance; target_density / density_weight / gamma; cross-tier-net wirelength model pulling both tier projections together; HBT count and placement near both endpoints' projection.
- Legality killers (candidate becomes INVALID): overlaps, off-row/off-site cells, out-of-boundary, HBT pitch/overlap violation (1um grid, >=1um spacing), broken cross-tier connectivity, legalization displacement beyond limit, missing metrics, exceptions, timeouts.
- Cross-PDK traps: ng45 uses metal1..metal20 (3D) with ns Liberty units; asap7 3D platform is unknown to you (M1..M9 mirrored, ps units, different DEF units/row height/site). Never hard-code layer names, units, row heights, site names, cell suffix lists or circuit names; derive them from LEF/DEF/config.
- Budget: 30 evaluations total; each is 9 full flows. One attributable change per candidate; prefer TNS (60% weight) over chasing a single worst path.
